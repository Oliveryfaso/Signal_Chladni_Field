# Local data samples

`product-pulse.csv` is synthetic, non-personal demonstration data. It exists only to exercise Signal Field's local Data Field flow:

1. Choose **数据场** in the visualizer.
2. Import `product-pulse.csv`.
3. Switch to **多指标合奏**.
4. Press play and use the timeline slider to inspect periods of elevated latency and errors.

No sample or user-provided data is uploaded by the application.
