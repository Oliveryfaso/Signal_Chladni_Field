# 产品升级方向：从音乐可视化器到“信号空间”

## 保留的原始能力

增强版以完整上游仓库作为底座，不删除网页、Electron 桌面端、系统音频/麦克风/本地文件输入、四种视觉模式、模式收藏、全屏与旋转控制、视频导出、macOS 屏保和锁屏启动器。原项目的源码、Apache-2.0 许可证和第三方素材声明保留在根目录。

## 已加入：专注场

`app/index.html` 新增 5/25/50 分钟专注会话。启动时会快照用户当前图案、旋转和速度，切换到稳定的 Cosmic Web 组合；会话结束或主动退出时恢复原场景。它不需要音频输入，因此产品不再只在“听歌”时有价值。

## 下一批高价值能力

### 1. 数据场（第一版已实现本地导入）

已支持拖入 CSV/JSON 数组、选择任一数值列、逐行播放和拖动查看时间点。数值映射到模态峰值，变化率变成额外谐波与能量，因此突增、突降与稳定区间会生成不同的粒子迁移方式。所有文件只在浏览器内存解析，不上传。

已加入“多指标合奏”：所有数值列均会占据不同的模态频段，列的平均值控制整体能量，跨列平均变化率控制结构锐度；变化特别剧烈时会显示 `△ 异常波`。下一步可把异常点保存为可回看的冲击波书签，并把每个时间点导出为场景配方。

### 2. 可交互物理实验室

增加“激振点”拖拽、频率扫频、模态频率标签、节点/腹部解释和截图对比。它把漂亮效果变成可教学、可展览、可用于课堂演示的工具。

### 3. 状态场景系统

建立可编排的场景状态机：开始工作、深度专注、短休息、演示待机、会议背景等。场景控制的不只是颜色，而是粒子密度、模态限制、相机、旋转、光源与转场曲线，并可分享为 JSON 配方。

### 4. 生产级桌面体验

在已有 Electron 基础上补齐多显示器状态、低功耗帧率、全局快捷键和 Windows loopback 音频设备兼容性。视频导出保留，但只作为创作输出而不是产品主叙事。

## 不做的事

不把上游受限制的品牌、图标、宣传媒体或独立音乐文件当作新产品资产；发布前要替换为自有品牌与有权使用的资源。
