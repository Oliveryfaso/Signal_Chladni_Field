# Contributing

Contributions are welcome, with current priority on the Windows music visualizer described in [README.md](README.md#windows-开发者招募).

## Code

By submitting a code, documentation, build, or configuration contribution, you agree that your contribution is licensed under Apache License 2.0. You must have the right to submit the contribution and must identify code copied or adapted from another source.

## Media And Pattern Presets

By submitting original screenshots, GIFs, videos, promotional artwork, or standalone pattern presets for inclusion in the project, you agree that those materials are licensed under CC BY-NC 4.0 as described in [ASSET_LICENSE.md](ASSET_LICENSE.md).

Do not submit third-party audio, images, video, fonts, models, or other assets unless their source and license are documented and redistribution within this repository is permitted. Pixabay content must not be redistributed on a standalone basis.

## Windows Work

Useful Windows contributions include loopback-audio compatibility, transparent overlays, multi-monitor and DPI behavior, installer and signing work, energy profiling, and visual-parity tests. Include the tested Windows version, audio device, display layout, and DPI settings with each compatibility change.
